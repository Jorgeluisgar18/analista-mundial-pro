## 3. Remediaciones aceptadas

- Rate limit: se cerró el bypass por `X-Forwarded-For` con tests de regresión.
- Payload excesivo: `POST /api/match/[id]/overrides` corta cuerpos grandes con 413 antes de `request.json()`.
- Backtesting: `scripts/run-backtest.ts` tolera resultados JSON corruptos y continúa con el resto de corridas.
- Persistencia: los fallos de escritura se registran y existe `strictPersistence` para flujos donde persistir sea obligatorio, sin romper la cabina principal.
