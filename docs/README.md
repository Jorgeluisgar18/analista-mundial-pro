# Documentación

Esta carpeta agrupa la documentación útil del proyecto sin mezclar guías activas con material histórico.

## Guías principales

- `guides/provider-setup.md`: configuración de proveedores y variables de entorno.
- `deployment/netlify-neon-postgres.md`: notas de despliegue con Netlify y Neon.
- `qa/manual-search-matrix.md`: matriz de pruebas manuales.
- `qa/production-smoke.md`: verificación rápida post-deploy.

## Producto y análisis

- `product/product-spec.md`: especificación funcional original.
- `data-sources/`: notas de proveedores y fuentes de datos.
- `model-validation/backtesting.md`: criterios de validación del modelo.
- `security/auth-workspace-decision.md`: decisión sobre autenticación futura.

## Coordinación interna

- `internal/handoff.md`: bitácora y empalme entre sesiones/agentes.
- `guides/claude-web-free-audit.md`: guía para auditoría externa usando Claude Web Free.

## Archivo histórico

- `archive/`: auditorías, planes antiguos, changelog de sesiones y evidencia histórica.

El material en `archive/` se conserva por trazabilidad, pero no debe tratarse como documentación operativa actual.
